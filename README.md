**resido** is an open-source and simple residential manager.

#### Tech stack

- [Tailwind](https://tailwindcss.com/) - CSS styling.
- [shadcn/ui](https://ui.shadcn.com/) - UI React components.
- [TanStack Start](https://tanstack.com/start/latest) - React framework.
- [Better Auth](https://www.better-auth.com/) - Auth.
- [PostgreSQL](https://www.postgresql.org/) - Database.
- [Drizzle](https://orm.drizzle.team/) - ORM.
- TBD - Hosting.
